# Автоматическая нарезка аудио по тишине и удаление пауз

## Технологии

* **Python 3**
* **auditok** — специализированная библиотека для токенизации аудио и поиска звука по уровню энергии.
* **tkinter** — встроенная библиотека Python для вызова системных диалоговых окон выбора файлов.
* **os** — встроенная библиотека для динамической работы с путями и создания папок.

## Предварительные требования (Установка необходимых библиотек Python)

* **Шаг 1:** Убедитесь, что у вас установлен Python (при установке обязательно поставьте галочку Add Python to PATH).
* **Шаг 2:** Сторонние утилиты (вроде FFmpeg) устанавливать не нужно — скрипт работает самостоятельно!
* **Шаг 3:** Установите единственную необходимую библиотеку для работы со звуком при помощи команды в терминале/командной строке:
`pip install auditok`

## Инструкция по запуску проекта

* **Шаг 1:** Запустите скрипт (например, через терминал командой `python main.py` или из вашей среды разработки).
* **Шаг 2:** На экране немедленно появится стандартное системное окно проводника. Выберите исходный аудиофайл (поддерживается только формат .wav).
* **Шаг 3:** Дождитесь завершения обработки — в консоли будет отображаться статус анализа и количество найденных кусков с речью.
* **Шаг 4:** Перейдите в папку, где лежал ваш исходный файл. Программа автоматически создаст там папки с результатами.

### Результаты работы:

* Все отдельные нарезанные фрагменты с речью сохранятся в папку `part_silense/` в формате `part_X.wav`.
* Единый склеенный файл без пауз сохранится в папку `full_silence/` с префиксом `no_silence_`.
